# 门店管家

本仓库用于发布门店管家 Windows x64 程序包与更新说明。

[下载最新版本](https://github.com/wanglanaaa/Store-Manager-Releases/releases/latest)

请下载 Release 附件中的 `StoreManager-版本号-win-x64.zip`，完整解压后运行 `StoreManager.WinForms.exe`。无需安装 Python 或 .NET；不要只复制 exe。

程序包不包含经营账套。更新前请备份账套，将新版解压到独立文件夹，打开原账套使用。数据库兼容要求以对应版本更新说明为准。

Release 中自动生成的 Source code 压缩包只包含本发布仓库的说明文件，请选择 Windows 程序包。
